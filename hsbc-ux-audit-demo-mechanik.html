Operating manual

3-step guide.

01 — Upload

Drop the source

A screenshot, source file, or design file. The agent reads what's there — no live URL needed.

02 — Scan

Run the audit

The engine checks 18 self-audit items across four bands: Customer Mindset, UX, UI, Copy.

03 — Decode

Review action items

A UX score, a Pass / Not-pass verdict, and a punch list ready for PR or Jira.

§G1Scoring protocolRead

Every audit item resolves to one of three states. Each band scores passes / total × 100. Overall is the average of the four bands. 70 is the pass threshold.

PassDetected in the uploaded file.
ReviewAmbiguous evidence; needs human confirmation.
MissingNot present; turns into an action item / Jira ticket.
